# フェーズ4 フェーズ3 コラボフォーム関連（★2・★3）の処理は不要と確定

- 日付: 2026-11-09
- 担当: 波多野（開発窓口） / Claude Code

## 背景・目的

フェーズ3の最後の保留項目だった「コラボフォーム申込み・解約時の条件付き必須（★2・★3）とサブドメインのセット」は、コラボフォームの契約・解約をどう判別するか、現在サブドメインの取得元はどこかが未確認だった。ユーザーが業務支援チームに確認し、結論を共有した。

## 確認結果（Reasoning）

ユーザーからの共有（業務支援チームの回答）：

- 規約合意系のフィールドは全て削除された。本項目（★2・★3）の処理も全て不要となった。
- 新規申込み時の規約合意は不要。コラボフォームの場合は、必ず事前に環境（対象サブドメイン）が作成されており、事前に規約合意がなされている状態であるため、ここで改めて合意を取る必要はない。
- 解約時の規約合意は不要。コラボフォームを使用している時点で、既に合意されている。
