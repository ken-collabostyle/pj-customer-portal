# AIエージェント実施記録

AIエージェントがReAct（Reasoning → Acting → Observation）サイクルで作業したタスクの記録を、タスク単位で保存するフォルダです。

## ファイル命名規則

```
YYYY-MM-DD_タスク概要.md
```

例: `2026-08-24_react環境構築.md`

## テンプレート

新規記録を作成する際は [TEMPLATE.md](TEMPLATE.md) をコピーして使用してください。

## 記録する理由

本プロジェクトは自社製品（コラボフロー・コラボフォーム）の活用事例でもあり、構築・運用の過程で得られた知見を製品改善やセールス提案へ還元することが目的の一つです（`docs/inception-deck.md` 参照）。そのため各記録には「得られた知見・製品への示唆」を必ず記載します。
