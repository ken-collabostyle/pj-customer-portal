# フェーズ1ステップa：TC-19（複数インスタンス時プルダウンのフォントサイズ崩れ）対応

- 日付: 2026-09-02
- 担当: Claude（ken-collabostyleの指示のもと）

## 背景・目的

TC-19（複数インスタンス時のプルダウンUI表示）は動作自体は正常だったが、ユーザーから「プルダウンになった際のフォントサイズが、ここだけ大きく見える」との指摘があり、参考として実機のフォームHTMLを共有いただいた。

## 調査内容（Reasoning）

共有されたHTMLを確認したところ、`fidContractedInstanceName`のネイティブ`<input>`には`mantine-Input-input mantine-TextInput-input mantine-ee2s1i`というMantineのCSSクラスが付与されており、フォントサイズ等を固定値（14px相当）で上書きしている。

一方、[monthly-contract-change.ts](../../src/forms/monthly-contract-change.ts)の`buildInstanceSelector`が動的生成する`<select data-role="instance-selector-fallback">`にはクラスを一切付与していなかった。ページのグローバルCSSリセット（`button,input,...,select,textarea{font-size:100%;...}`）により、クラスなしの`<select>`は祖先要素（テーブルセルに直接指定された`font-size:14pt`≒18.7px）のfont-sizeを継承してしまい、Mantineの入力欄が使う14px前後より一回り大きく表示されていたことが原因と特定した。

## 実施内容（Acting）

- [monthly-contract-change.ts](../../src/forms/monthly-contract-change.ts)の`buildInstanceSelector`で、`<select>`生成直後に`select.className = nativeInput.className;`を追加し、ネイティブinputと同じMantineクラスを付与
- `npm run lint` / `npm run typecheck` / `npm run test` / `npm run build`をすべて実行し成功を確認

## 結果・観察（Observation）

- `npm run lint`：エラーなし
- `npm run typecheck`：エラーなし
- `npm run test`：16件全て成功
- `npm run build`：`dist/forms/monthly-contract-change.js`再生成を確認
- 実機での見た目確認（プルダウンのフォントサイズが他のパーツと揃うか）は未実施。ユーザーが検証環境で確認予定
- `npm test`を`npm run lint && npm run typecheck && npm test && npm run build`のように連続実行した直後の初回のみ、テストコード・対象コードに変更がないにもかかわらず`Cannot read properties of undefined (reading 'config')`というvitestランナー起動時の一過性エラーが再現した。単体で複数回再実行すると安定して16件成功するため、コード側の問題ではないと判断（[実機確認と対応](2026-09-02_フェーズ1ステップa_実機確認と対応.md)でも同事象を観測済み）

## 得られた知見・製品への示唆

- コラボフォームのカスタムJSでDOM要素を動的生成する場合、Mantineコンポーネント（`.mantine-Input-input`等の共通クラス）を流用することで、フォントサイズ・パディング・ボーダー等の見た目をネイティブパーツと自動的に揃えられる。今後DOM操作を伴う非公式実装を追加する際は、生成する要素に既存パーツのclassNameをコピーする手法を標準パターンとして検討したい
- `npm test`を他コマンドと連続実行した直後の初回のみvitestが`Cannot read properties of undefined (reading 'config')`で落ちる事象が複数回（本記録および[実機確認と対応](2026-09-02_フェーズ1ステップa_実機確認と対応.md)）で再現している。単体再実行では安定するためコードの問題ではなくローカル環境のvitest起動タイミングに起因する可能性が高いが、再現条件が掴めておらず未解明。今後CI等で同様の事象が出た場合は要調査
