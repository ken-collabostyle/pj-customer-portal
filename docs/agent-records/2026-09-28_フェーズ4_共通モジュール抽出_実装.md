# フェーズ4 共通モジュール抽出

- 日付: 2026-09-28
- 担当: 波多野（開発窓口） / Claude Code

## 背景・目的

[フェーズ4計画](../plans/2026-09-25_フェーズ4_年額契約変更カスタマイズ計画.md)のアーキテクチャ方針に基づき、年額版フォームのフェーズ1着手前に、月額版と完全に同一のロジック（営業日計算・変更適用年月、オプションユーザー数整合性チェック）を共通モジュールへ切り出す。

## 調査内容（Reasoning）

`src/forms/monthly-contract-change-logic.ts`を確認し、フォーム固有のフィールドコード・パーツIDに依存しない汎用ロジック（`isBusinessDay`等・`findUserCountMismatches`等）と、依存する関数（`toContractRecord`・`buildLineItems`等）を切り分けた。両者が参照する`BASE_CATEGORY`定数は、フォーム固有関数（`findBaseRecord`）からも使われるため、共通モジュール側へ移し月額側からimportする方針とした。`monthly-contract-change.ts`・テストファイルの参照元も洗い出し、詳細計画（[2026-09-28_フェーズ4_共通モジュール抽出.md](../plans/2026-09-28_フェーズ4_共通モジュール抽出.md)）としてユーザー承認を得た。

## 実施内容（Acting）

1. `src/forms/contract-change-shared-logic.ts`を新規作成し、`isBusinessDay`, `getBusinessDaysOfMonth`, `getCutoffBusinessDay`, `computeEarliestAllowedApplyMonth`, `isApplyMonthSelectionAllowed`, `ApplyMonth`型, `toDateKey`（内部ヘルパー）, `OPTION_CATEGORIES`, `findUserCountMismatches`, 関連する型, `BASE_CATEGORY`を移動（中身は無変更）
2. `monthly-contract-change-logic.ts`から該当コードを削除し、`BASE_CATEGORY`を`contract-change-shared-logic.ts`からimportするよう変更
3. `monthly-contract-change.ts`のimportを、移動した関数について`./contract-change-shared-logic`からのimportに変更
4. `tests/forms/monthly-contract-change-logic.test.ts`から該当`describe`ブロックを`tests/forms/contract-change-shared-logic.test.ts`（新規）へ移動し、それぞれのimportを更新

## 結果・観察（Observation）

`npm run lint` / `npm run typecheck` / `npm test` / `npm run build`をすべて実行し通過を確認。テストは分割後、`contract-change-shared-logic.test.ts`26件・`monthly-contract-change-logic.test.ts`16件の計42件で、移動前の単一ファイルのテスト数（42件）と一致し、テストケースの過不足がないことを確認した。

なお検証中、`npm run lint && npm run typecheck && npm test`を`&&`で連結して実行した際に一度だけ`vitest`が`Cannot read properties of undefined (reading 'config')`で失敗する事象が発生したが、各コマンドを個別に実行し直すと全て正常に通過した。原因はコマンド連結時の一時的な事象とみられ、コード側の問題ではないと判断した。

関数のシグネチャ・挙動は変更していないため、実行時挙動への影響はなく、検証環境での実機確認は実施していない。

## 得られた知見・製品への示唆

月額版と年額版で共通のロジックを`contract-change-shared-logic.ts`に集約したことで、年額版フェーズ1（ステップa・b・c・d）の実装時にこのモジュールをそのまま参照できる状態になった。今後、他フォーム（解約届等）でも同様の営業日計算・数量整合性チェックが必要になった場合、この共通モジュールを再利用できる可能性がある。
