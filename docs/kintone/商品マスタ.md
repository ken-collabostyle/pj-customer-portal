# kintoneアプリ「商品マスタ」

オプション等を新規追加する場合の「定価」を取得するためのアプリ。[クラウド契約管理DB](クラウド契約管理DB.md)には定価情報が含まれないため、こちらを参照する。

取得方法：kintone REST API `GET /k/v1/records.json?app={KINTONE_PRODUCT_MASTER_APP_ID}&query=...`。認証情報は`.env`の`KINTONE_BASE_URL` / `KINTONE_PRODUCT_MASTER_APP_ID` / `KINTONE_PRODUCT_MASTER_API_TOKEN`を使用（実値はこのファイルに書かない）。

## フィールド対応表（確度高）

| 要求事項の項目 | kintoneラベル | フィールドコード | 型 | 備考 |
|---|---|---|---|---|
| 単価（新規追加時の定価） | 標準売価 | `標準売価` | NUMBER | |
| 商品コード（[クラウド契約管理DB](クラウド契約管理DB.md)の`製品型番`と照合するキー） | メーカー型番 | `文字列__1行_` | SINGLE_LINE_TEXT | 2026-08-25 ユーザー確認済み |
| 商品名 | 商品名(正式名称) | `文字列__1行__0` | SINGLE_LINE_TEXT | |
| 月額／年額の区分 | 月額／年額 | `月額年額` | RADIO_BUTTON | クラウド契約管理DBの`月額・年額`と同様、月額のみを対象にする想定 |
| 販売終了フラグ | 販売終了フラグ | `販売終了フラグ` | CHECK_BOX | 新規追加候補から除外する判定に使える可能性 |

## 参考：その他のフィールド（今回の要求事項では未使用と思われるもの）

商品区分(`ドロップダウン`)、商品分類コード(`ドロップダウン_0`)、オンプレ/クラウド(`ラジオボタン`)、単位(`ラジオボタン_0`)、按分月数(`数値`)、課税区分(`数値_0`)、商品区分2(`文字列__1行__1`)、検索ワード（型番）(`文字列__1行__3`)、期間表示(`期間表示`)、検索用フィールド（`検索_契約管理`, `検索ワード`, `検索ワード_NON`）、見積検索対象外(`見積検索対象外`)。
