# kintoneアプリ「商品マスタ」

オプション等を新規追加する場合の「定価」を取得するためのアプリ。[クラウド契約管理DB](クラウド契約管理DB.md)には定価情報が含まれないため、こちらを参照する。

取得方法：kintone REST API `GET /k/v1/records.json?app={KINTONE_PRODUCT_MASTER_APP_ID}&query=...`。認証情報は`.env`の`KINTONE_BASE_URL` / `KINTONE_PRODUCT_MASTER_APP_ID` / `KINTONE_PRODUCT_MASTER_API_TOKEN`を使用（実値はこのファイルに書かない）。

フィールドコードは`getFormFields` APIで取得した生レスポンス（[docs/kintone/json/商品マスタ_getFormFields.json](json/商品マスタ_getFormFields.json)、2026-09-02取得）を一次情報とする。**下表は2026-09-02にこの生JSONと突合し、以前の版に含まれていたフィールドコードの誤りを修正済み**（誤：`標準売価`→正：`標準単価`（ラベルが「標準売価」なので紛らわしいが、コードは異なる）、誤：`月額・年額`→正：`月額年額`）。

## 未確認事項・今後のヒント（2026-09-02 生JSON突合で判明）

- `ラジオボタン_0`（ラベル「単位」、選択肢：本／回／式）というフィールドが存在する。[フェーズ1ステップaの実施記録](../agent-records/2026-09-02_フェーズ1ステップa_インスタンス名UIとkintone連携_実装.md)で未解決課題として残した「明細の変更後商品単位（`fidChangedProductUnit`）のデータソース不明」に対し、`製品型番`（クラウド契約管理DB）と`文字列__1行_`（メーカー型番、本アプリ）を突合すればこのフィールドから単位を取得できる可能性がある。ただし実装（プロキシAPI呼び出し・突合ロジックの追加）は別途検討が必要なため、現時点ではドキュメント記載のみ。
