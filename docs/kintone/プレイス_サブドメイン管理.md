# kintoneアプリ「プレイス_サブドメイン管理」（アプリID: 81）

コラボフローのインスタンス（顧客）ごとに、使用しているサブドメインを管理するアプリ。契約変更フォームの `fidCollaboformSubdomain`（サブドメイン）・`fidCollaboformCurrentSubdomain`（コラボフォーム現在サブドメイン）にセットする値の取得元（2026-11-18確定。[実施記録](../agent-records/2026-11-18_フェーズ4フェーズ3サブドメイン2パーツは残し取得元はサブドメイン管理アプリと確定.md)参照）。

- 認証方式：**APIキー（APIトークン）認証**。開発時の疎通確認用に、`.env`の`KINTONE_PLACE_SUBDOMAIN_MANAGEMENT_APP_ID` / `KINTONE_PLACE_SUBDOMAIN_MANAGEMENT_API_TOKEN`を使う（[.env.example](../../.env.example)参照）。実値はこのファイルに書かない。コラボフォームのプロキシAPI（管理画面＞プロキシAPI）のリクエストヘッダーに設定する想定（[README](README.md)参照）。
- 取得方法（案）：`GET /k/v1/records.json?app=81&query=インスタンス名="{インスタンス名}"`
- フィールドコードは一次情報の[json/プレイス_サブドメイン管理.json](json/プレイス_サブドメイン管理.json)（`getFormFields`相当、revision 8、2026-11-18追加）に基づく。
