# kintoneアプリ「ライセンス種類マスタ」

[商品マスタ](商品マスタ.md)に代わり、新規追加オプション等の「定価」および商品のライセンス形式（ベース／オプション等の区分）を取得するためのアプリ。2026-09-11、ユーザーが業務支援チームと調整し、本アプリに「月額単価」フィールドを追加。本プロジェクトでは商品マスタは使用せず、本アプリを参照する方針に変更された。

取得方法：kintone REST API `GET /k/v1/records.json?app={KINTONE_LICENSE_TYPE_MASTER_APP_ID}&query=...`。認証情報は`.env`の`KINTONE_BASE_URL` / `KINTONE_LICENSE_TYPE_MASTER_APP_ID` / `KINTONE_LICENSE_TYPE_MASTER_API_TOKEN`を使用（実値はこのファイルに書かない、キー名は暫定案のため設定時に確定させる）。

フィールドコードは`getFormFields` APIで取得した生レスポンス（[docs/kintone/json/ライセンス種類マスタ_getFormFields.json](json/ライセンス種類マスタ_getFormFields.json)）を一次情報とする。

## 突合キー（2026-09-11ユーザー確認済み）

クラウド契約管理DBの`ライセンス種類マスタ読込`フィールドの値と、本アプリの`検索ワード`フィールドの値が一致するレコードを突合する。クラウド契約管理DB側の`ライセンス種類マスタ読込`はLOOKUP型ではない通常のテキストフィールドのため、**フォーム上でリアルタイムに自動連携されるものではない**（JSから別途ライセンス種類マスタへの問い合わせが必要）。
