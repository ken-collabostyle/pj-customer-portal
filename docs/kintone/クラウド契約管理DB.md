# kintoneアプリ「クラウド契約管理DB」（アプリID: 73）

「顧客番号」をキーに検索し、対象顧客の契約中ライセンス・商品を明細形式で取得する。**1レコード＝1顧客の1商品／1ライセンス行**という構造（顧客番号で複数レコードを取得し、フォームの「ご注文内容」明細に対応させる想定）。

取得方法：kintone REST API `GET /k/v1/records.json?app=73&query=顧客番号="{顧客番号}"`（フィールドコード`顧客番号`でクエリ）。認証情報は`.env`の`KINTONE_BASE_URL` / `KINTONE_CONTRACT_DB_APP_ID` / `KINTONE_CONTRACT_DB_API_TOKEN`を使用（実値はこのファイルに書かない）。

フィールドコードは`getFormFields` APIで取得した生レスポンス（[docs/kintone/json/クラウド契約管理DB_getFormFields.json](json/クラウド契約管理DB_getFormFields.json)、2026-09-02取得）を一次情報とする。**下表は2026-09-02にこの生JSONと突合し、以前の版に含まれていたフィールドコードの誤りを修正済み**（誤：`月額・年額`→正：`月額年額`、誤：`単価_月額税抜`→正：`単価_月額_税抜`、誤：`契約金額_月額のみ税抜`→正：`契約金額`、誤：`種類2`（半角2）→正：`種類２`（全角2））。

## 未確認事項（2026-09-02 生JSON突合で新たに判明、要ユーザー確認）

- **明細の「商品名」に使えるフィールドが要求事項側の対応表に未定義**。生JSONには`サービス名_請求書用`（ラベル「サービス名（請求書用）」）というフィールドがあり、商品名相当として使えそうだが未確認。
- **`契約ステータス`とは別に`契約ステータス2`という詳細ステータスが存在**（選択肢：解約／切替／契約中／変更予約中／保留中）。「現在契約中の行」を絞り込む際、既存の`契約ステータス`（「契約中」の一択）だけで十分か、`契約ステータス2`も見るべきかが未確認。
- `区分`の選択肢は生JSON上「ベース」「オプション」「オプション（ライセンスキー不要」「オプション（転記不要）」「フォーム」「フォームOP」の6種（一部ラベルの閉じ括弧が欠落しているが、kintone側の設定ミスとみられる。フィールドコードとしては影響なし）。
