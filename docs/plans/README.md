# 作業計画

進行中の作業計画を保存するフォルダです。[docs/agent-records/](../agent-records/) が「完了したタスクの実施記録」であるのに対し、こちらは「これから・現在進めている作業の計画と進捗」を保存します。

作業を中断・再開する際は、まず対象の計画ファイルを読めば現在地（どのフェーズ・どのステップまで完了しているか、何が確認待ちか）がわかるようにします。

## ファイル命名規則

```
YYYY-MM-DD_タスク概要.md
```

日付は**計画を最初に作成した日**とし、以降は同じファイルを更新し続けます（agent-recordsのような追記専用の記録ではなく、進捗に応じて内容を書き換える生きたドキュメントです）。

## フォーマット

各計画ファイルの先頭に以下のフロントマターを付けてください。

```markdown
---
type: plan
date: YYYY-MM-DD       # 作成日
status: in-progress    # in-progress | on-hold | completed
tags: []                # 対象フォーム名・機能領域など
related: []             # 関連ドキュメント（要求事項、inception-deck等）へのパス
---
```

本文にはフェーズ・ステップごとのチェックリストを含め、完了したステップにはチェックを入れて更新してください。ステップが確認待ち・ブロック中の場合はその理由と確認先を明記します。

計画にもとづく作業が完了したら、`status: completed` に更新した上で、対応する実施記録を[docs/agent-records/](../agent-records/)に作成し、`related`で相互参照してください。

## マニフェスト

[manifest.md](manifest.md) に一覧を保守しています。新規計画を作成したら、必ずマニフェストにも1行追記してください。
