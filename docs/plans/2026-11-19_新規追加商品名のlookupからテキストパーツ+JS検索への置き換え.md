# 新規追加商品名（fidAddedProductName）のlookupからテキストパーツ＋JS検索への置き換え

## 背景
lookupでは「ベースライセンスに応じた表示フラグでの絞り込み」等の要件を満たせないため、テキストパーツ＋JS（プロキシAPI経由のkintone検索＋サブウィンドウ）で代替する。

## 要件（ユーザー指示 2026-11-19）
- テキストパーツに薄い虫眼鏡を表示し、参照可能パーツであることを示す
- クリックでサブウィンドウに「商品名_マイページ用」の検索フィールドを表示
- 検索時の自動絞り込み: 月額／年額=月額、オンプレ/クラウド=クラウド、ベースライセンスに対応する「表示」フラグ=表示、販売終了フラグ=空、見積検索対象外=空
- 結果一覧の表示: メーカー型番・商品名_マイページ用・標準売価
- 行クリックで追加商品名・追加商品コード・追加商品単価をセット

## 確定事項（ユーザー回答 2026-11-19）
- lookupで自動セットされていた追加商品区分（`文字列__1行__5`）も行選択時にセットする。年額版は按分月数（`数値`）も同様
- ベースライセンスは既存のkintone契約情報（`種類２`）から取得
- 商品マスタのフィールド情報は既存の`商品マスタ_getFormFields.json`に必要なコードが含まれている（再取得不要）
- プロキシAPIはユーザー（管理者）が管理画面で設定。設定案はこちらで用意
- 月額版・年額版で別名エンドポイント
- 検索ワードが空でも固定条件で一覧表示。上限20件

## フィールドコード対応（商品マスタ）
| 項目 | コード |
|---|---|
| メーカー型番（商品コード） | `文字列__1行_` |
| 商品名_マイページ用（検索対象・名称セット値） | `商品名_マイページ用` |
| 標準売価 | `標準単価` |
| 商品区分2 | `文字列__1行__5` |
| 按分月数（年額のみ） | `数値` |
| 月額／年額 | `月額年額`（月額） |
| オンプレ/クラウド | `ラジオボタン`（クラウド） |
| スタンダード／プレミアム／エンタープライズ／アカガバ 表示 | `スタンダード_表示`／`プレミアム_表示`／`エンタープライズ_表示`／`直販アカガバ_表示`（選択肢「表示」） |
| 販売終了フラグ／見積検索対象外 | `販売終了フラグ`／`見積検索対象外`（空） |

## 判明した注意点
契約DBの`種類２`の実値は「スタンダードプラン」「プレミアムプラン」「エンタープライズプラン」と、末尾に「 アカデミック/ガバメントライセンス」が付くもの（例：「プレミアムプラン アカデミック/ガバメントライセンス」）がある。他に「ライトプラン」「プロプラン」（区分=フォーム）も存在。
- 判定: 「アカデミック/ガバメント」を含む→アカガバ（最優先）／それ以外はプラン名に含まれる語で判定
- どれにも該当しない場合は検索を実行せず案内を表示（要・実機確認）
