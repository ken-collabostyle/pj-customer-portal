## JavaScript API/CSSとは？

コラボフォーム JavaScript API/CSSは、管理者がアップロードしたJavaScriptファイル・CSSファイルを公開フォームに読み込み、フォームの動作や見た目を拡張する機能です。

実現できること:

- フォームの表示・入力・確認・送信などのタイミングで独自の処理を実行する
- フォームのパーツ（入力項目）の値や状態を取得・変更する
- 外部のAPIを安全に呼び出す（プロキシAPI経由）
- CSSファイルによってフォームの見た目（デザイン）をカスタマイズする

利用するには、フォーム設定＞カスタマイズからJavaScriptファイル・CSSファイルのアップロードが必要です。

注意点:

- カスタマイズは、フォーム設定＞表示設定の**プレビューには適用されません**（公開フォーム・送信済みフォームのみ）。
- JavaScriptファイル/CSSファイルは、**管理者のメンバーのみ**設定できます（フォーム管理者は不可）。
- 本APIはJavaScript/CSSの基本的な技術知識を持つユーザー向けに提供されています。

## 利用準備

### 利用可能なユーザー

[コラボフォームご利用規約](https://collaboform.zendesk.com/hc/ja/articles/4583178470415)に同意済みのコラボフォーム利用中ユーザーであれば誰でも利用可能（特別なライセンス不要）。ただし設定操作自体は管理者ロールのみ。

### 必要なもの

- **Webブラウザー**: コラボフォームの動作環境に記載のブラウザー
- **JavaScript/CSSとコラボフォームの知識**: 基本的な技術知識と、コラボフォームの各種設定・運用に関する一般的な知識
- **テキストエディタ**: UTF-8を扱えるエディタ・IDE
- **コラボフォームの管理者ロール**: 利用できるのは管理者のメンバーのみ

## 制限事項

### ファイル・アップロードの制限

| 項目 | 制限 |
|---|---|
| ファイルサイズ | JavaScript / CSS各ファイル、1ファイルあたり5MBまで |
| ファイル数上限 | 1フォームにつき JavaScript / CSS それぞれ100件まで |
| カスタマイズの適用範囲 | 公開フォーム・送信済みフォームのみ（表示設定のプレビューには非適用） |

### 変数・ネームスペース

既存のグローバルオブジェクトを書き換えると、コラボフォームが正常に動作しなくなる可能性があります。複数スクリプト間の変数名衝突を防ぐため、**即時実行関数（IIFE）のローカルスコープ**として変数を定義することを推奨します。

```javascript
(function () {
  "use strict";
  const local = 1; // 良い例
  global = 1;       // 悪い例（グローバル変数への代入）
  collaboform.var1 = {}; // 既存オブジェクトの書き換えは不可
})();
```

### 複数ファイルの読み込み順序

複数のJS/CSSファイルをアップロードしている場合、読み込み順序はフォーム設定＞カスタマイズ＞JavaScript/CSSカスタマイズの「アップロードしたファイル」に表示される順番（JS・CSSは個別に管理）。ドラッグ＆ドロップで並び替え可能。処理順に依存するカスタマイズでは要注意。

### DOM構造への依存

コラボフォーム要素のid/class属性名やDOM構造は**事前通知なく変更される場合がある**。id/class名やDOM構造に依存しないカスタマイズを心がける。表示設定（デフォルト表示⇔シンプルフォーム表示）の切り替えでDOM構造が大きく変わるため、切り替え時の動作確認が必須。

### パーツの変更・削除

連携するコラボフローでパーツの変更・削除を行うと、そのパーツの存在・設定を前提としたカスタマイズが正常に動作しなくなる可能性がある。変更前に影響確認が必要。

### CSSファイルの利用

今後のアップデートによるデザイン変更でレイアウトが崩れる可能性があり、スタイルの保証はされない。

### 外部ライブラリの利用

- コラボフォーム内部で使用中のライブラリと同名・同バージョンのライブラリを読み込むと誤動作の可能性がある。想定外の動作時はまず外部ライブラリを外して確認する。
- 外部ライブラリはURL指定による動的読み込み不可。ファイルをダウンロードしJS/CSSファイルとしてアップロードする必要がある。

### 外部リソースの動的な読み込み制限（セキュリティ）

以下はブロックされる:

- `<script src="外部URL">` によるスクリプトタグの動的読み込み
- `@import` や動的な `<link rel="stylesheet">` による外部スタイルシートの読み込み

外部公開のJS/CSSを使いたい場合は、ダウンロードしてアップロードする。

### パーツ（`parts` オブジェクト）の制限事項

- 未対応パーツ（時刻パーツ・画像パーツ）は `data.parts` に含まれない。対応パーツ一覧: [コラボフォームに対応しているフォームパーツと設定](https://collaboform.zendesk.com/hc/ja/articles/8471313195791)
- `enabled` 値は取得のみ可能（設定によるパーツの有効/無効切り替えは不可）

詳細は [parts-reference.md](parts-reference.md) を参照。

### 外部API実行（プロキシ）の制限事項

- 接続先プロトコルは `https://` のみ
- `localhost` およびローカルネットワークアドレスへの接続は禁止
- 受信ボディの上限は10MiB（10,485,760バイト）
- 応答待ち時間（受信タイムアウト）は120秒

詳細は [proxy-api.md](proxy-api.md) を参照。

### カスタマイズファイルの適用対象（バージョニング）

カスタマイズファイルは、コラボフローのフォームの**版（バージョン）ごとに管理**される。

- 最新版に保存したカスタマイズは、新規送信および同じ版の送信済みフォームに即時適用される。
- 過去の版の送信済みフォームには、その版で最後に保存されたカスタマイズが適用される（過去版へのカスタマイズ編集は不可）。
- コラボフロー側のフォーム編集で版が更新されると、カスタマイズは自動的に引き継がれる。
- フォームの経路設定変更によりコラボフロー側のフォームが変わった場合、カスタマイズが意図通り動作しない可能性がある。

### コラボフォームのアップデートによる影響

コラボフォーム本体のアップデートにより、既存のJS/CSSカスタマイズが動作しなくなる場合がある。その場合は必要に応じて修正・再アップロードする。
