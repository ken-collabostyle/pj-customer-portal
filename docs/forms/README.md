# 対象フォーム ひな形

[inception-deck.md](../inception-deck.md) 4章「スコープ」に記載の対象フォーム7種類について、業務支援チームより受領した空フォーマット（Excel、顧客データなし）を格納します。

## 設定フロー

1. 本フォルダのExcelひな形を**コラボフロー**にインポート
2. コラボフロー上でフォームに変換
3. コラボフローAPI（[`getFormParts`](../collaboflow-api/README.md)）でフォームのパーツ構造をJSON取得し、[json/](json/) に保存
4. **コラボフォーム**で公開
5. 必要な入力チェック等は[コラボフォームJavaScript API](../collaboform-js-api/README.md)でカスタマイズ（パーツIDは3.のJSONで確認）

## 注意事項

- 格納するファイルは**空フォーマット（顧客データを含まないもの）に限る**こと。記入済みサンプルや実データを含むファイルはコミットしない。
- コラボフロー側でひな形を修正した場合は、差分管理のためこのフォルダのファイルも更新すること。
- Excelファイルはバイナリのため、`git diff`では中身の変更点は確認できない点に留意する。
- `json/`配下のパーツ構造JSONも、フォーム側の設定変更（パーツ追加・削除・ID変更等）があれば都度再取得して更新すること。JSON自体はテキストのため`git diff`で差分確認が可能。
