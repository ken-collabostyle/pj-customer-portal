# README

## インセプションデッキ

## 1\. ミッション

自社製品を用いた顧客向けマイページを構築し、これまで手作業で対応していた契約変更などの手続きをオンライン化することで、業務支援チームの受発注業務を効率化する。

あわせて、構築や運用の過程で得られた知見を製品改善及び提案に繋げる。

## 2\. エレベーターピッチ

顧客マイページは、メールやExcelで行っていたコラボフローの契約変更やライセンス追加等の手続きをオンライン化するポータルシステムです。契約者自身がWeb上で各種申請を行えるようにすることで、業務支援チームの受注・納品業務の負担を軽減します。

また、自社プロダクト（コラボフロー・コラボフォーム）を用いて構築する事で、業務効率化だけでなく社内活用事例の創出や製品改善への還元にも繋がります。

## 3\. プロダクトの価値・ユーザー体験

### **価値**

* **顧客（コラボフロー契約者）：**   
  手続きのオンライン化により申込から完了までの日数が短縮される。また、現在の契約内容や過去の申請履歴、送信後の進捗状況を把握できるようになり、問い合わせの手間が減る。  
* **業務支援チーム（受発注担当者）：**   
  Excelファイルの受け渡しやメール返信に伴う手動作業が削減され、受注・納品業務の負担が軽減される。手入力や転記に伴うミスおよび確認漏れのリスクも低減される。  
* **製品開発・セールス担当者：**   
  「コラボフロー」および「コラボフォーム」を活用した具体的な運用実績が得られ、製品改善や提案活動に活用できる。

### **ユーザー体験**

* **顧客（コラボフロー契約者）：**   
  マイページにログインし、画面上で現在の契約内容（プランやライセンス数など）を確認した上で各種変更等の申請を行う。申請完了後は、マイページ上で該当申請の進捗状況（受付済、処理完了など）を確認する。  
* **業務支援チーム（受発注担当者）：**   
  顧客がWeb上から入力したデータがシステムに直接連携されるため、メール受信後の手動転記作業を行わずに後続の処理へ移行する。  
* **製品開発・セールス担当者：**   
  自社運用を通して抽出された課題を製品改善へフィードバックする。また、顧客向けの提案時には、具体的な社内運用事例として実際の運用を参照する。

## 4\. スコープ

**対象フォーム（7種類）**

* 【コラボフロークラウド版】注文書兼利用申込書（月額：契約変更）  
* 【コラボフロークラウド版】注文書兼利用申込書（年額：契約変更）  
* 【コラボフロークラウド版】解約届（全解約）  
* 【コラボフロークラウド版】お客様情報変更届v1  
* 【コラボフロークラウド版】請求情報変更届v1  
* 【コラボフローパッケージ版】お客様情報変更届v1  
* 【コラボフローパッケージ版】請求情報変更届v1

**主な機能・要件**

* kintoneからの現在契約情報の取得および表示  
* kintoneからのマスター参照による追加商品取得  
* プラン変更、一部解約、年額変更等の受付処理  
* JavaScriptカスタマイズによる各種入力チェック機能の実装

**やらないこと（Out of Scope）**

* パッケージ版の注文書兼利用申込書の実装

## 7\. プロジェクト条件

**技術・システム的な条件**

* マイページの構築には、自社プロダクトである「コラボフロー」および「コラボフォーム」を必ず使用すること。  
* 現在の契約情報や商品マスターのデータ参照元として、kintoneと連携する構成とすること。

**プロジェクトの目的・運用上の条件**

* 単なる社内業務の効率化にとどまらず、社内活用事例として対外的にアピール（販売・提案活動への活用）ができる品質と設計にすること。  
* 構築および運用の過程で得られた課題や知見は、製品の改善要望としてフィードバックすること。

**スケジュールに関する条件**

* 11月中旬ごろまでに、カスタマイズ等の機能面の実装を完了させること。以降はリリース等に向けた調整期間とする。
